# FO76 HUD permissions — quick rules

> Load full `SKILL.md` when executing this workflow.

- Decide rights per artifact and per requested action.
- Public access is not an open-source license.
- Local possession is not ownership or release permission.
- Track source, author, version, hash, license, conditions, and reviewer.
- Treat decompiled code and extracted assets as separate artifacts.
- Treat vanilla/game files as local runtime inputs only.
- Missing, stale, ambiguous, or conflicting evidence fails closed.
- `inspect-only` never implies modify or redistribute.
- Modification and redistribution need separate explicit clearance.
- Apply the most restrictive applicable condition.
- Generate attribution and notices from the ledger.
- Never apply this repository's license to third-party or vanilla files.
- Do not use a force override for a blocked release.
- Do not create a mod-service-derived AI corpus without permission.
